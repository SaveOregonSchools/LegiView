Help and Data Sources

LegiView is a local, provenance-first archive for Oregon House Bills and Senate Bills. Phase 1 collects one bill or one explicitly selected session and retains validated source files without destructive mirroring.

Collecting a Bill

  1. Choose the official session and bill.

    Enter a session key such as 2026R1 and an HB/SB identifier such as SB1501.

  2. Follow the durable run.

    The run detail page shows explicit stages from session/reference loading through discovery, download, and finalization.

  3. Review the archived bill.

    Bill detail separates chief and regular sponsors and groups testimony, presentations, floor letters, and other committee documents.

  4. Retry only what failed.

    Completed files that still exist and validate are skipped; retry does not require recollecting the entire bill.

Runs, Restarts, and Retry

Collection and downloading happen in bounded background workers, not inside the browser request. Run state, current stage, counters, work items, and errors are persisted. If the process stops, work that had been active is normalized to an interrupted state rather than left falsely running.

Use Run History to inspect progress. Use Retry Failures for retryable HTTP failures, interrupted downloads, low-space pauses after space is restored, or files later found missing locally.

Archive Layout and File Safety

Example<archive_root>/2026R1/SB1501/public_testimony/244133/document.pdf
  • Downloads stream into a .part staging file and are atomically finalized only after validation.
  • Every completed payload records byte count, MIME information, SHA-256, and a relative archive path.
  • A changed payload is retained as another document version; earlier bytes are not silently overwritten.
  • Filenames and paths are sanitized for Windows and registered before any local open/reveal action.
  • LegiView does not execute downloaded content. Treat every PDF or Office file as untrusted.

Official Sources and Acceptable Use

Oregon Legislature OData is the preferred structured source. LegiView requests only known OLIS testimony pages where the displayed document list or historical presentation context must be reconciled. It is not a general-purpose crawler.

Phase 1 Boundaries

Phase 1 does not perform multi-year backfill orchestration, scheduling, full-text indexing, OCR, semantic analysis, antivirus scanning, cloud hosting, or destructive source mirroring. It establishes the trustworthy collector, schema, downloader, durable run model, CLI, and local Flask interface that later phases can scale.
